Add to Terroir Map

Add a coffee farm, mill or auction to the map. Fill in the fields below, check the preview, then press Add to map. The live map updates about a minute later.

What are you adding?

Optional. Up to three coffee varieties grown on the farm, separated by commas. Shown under the farm's name on the map.

Where is it?

Click the map to place it (drag the pin to adjust), type the latitude and longitude, or paste coordinates copied from a map app. Coloured dots are entries already on the map.

From Google Maps: right-click the spot and click the numbers at the top of the menu to copy them (latitude first, then longitude).

North–south position in decimal degrees, −90 to 90. South of the equator is negative.

East–west position in decimal degrees, −180 to 180. West of Greenwich (the Americas) is negative.

Shown when people hover over the dot, so they know how far to trust the position. If you only know the town, pick the town option and use the town's coordinates.

Saving writes the entry to the map's repository on GitHub, which needs a token with permission to change it. The token is only sent to GitHub.

        
        

          How to get a token (one-off, about 2 minutes)
          
    
            
  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
    2. 
            
  2. Give it a name (e.g. "Terroir Map data entry") and an expiry date.
    3. 
            
  3. Under Repository access, choose Only select repositories and pick brygmanden/terroirmap.
    4. 
            
  4. Under Permissions → Repository permissions, set Contents to Read and write.
    5. 
            
  5. Generate it, copy it, and paste it above. Treat it like a password: anyone with it can change the repository's files.
    6.
